股感 Stockroom
台股觀察與簡易趨勢判讀系統

以 AI 協助從題目發想、需求討論，到可操作的網頁實作。

整理日期：2026/10/18（台北時間）｜階段：已完成本機功能驗證；GitHub Pages 公開部署待使用者完成。
創作動機範圍與流程功能與驗收資料規則技術架構AI 協作紀錄

01 · 創作動機與使用者

原本想做結合遊戲或生活工具的作品，討論後選擇自己有興趣的股票主題。希望把關注股票的行情、不同產業的強勢股，以及簡單的趨勢判讀集中在同一個網頁，減少在不同頁面之間查找資料。

目標使用者：希望練習觀察台股的學生與初學者。使用者不需要註冊，即可建立自己的觀察清單並查看歷史走勢。

核心目標：讓使用者能新增自選股、比較收錄產業的漲跌幅，並理解「實際行情」與「規則判讀」的差別。作品是學習與資訊整理工具，不提供交易功能。

02 · 實作範圍與操作流程

以台股為市場範圍，採深色版面與紅漲綠跌。主要分成「我的自選股」與「產業排行榜」，並有個股詳細資訊。

開啟首頁 → 查看資料交易日 → 搜尋股票名稱或代碼 → 加入自選清單 → 點選股票 → 切換歷史走勢期間 → 閱讀均線方向判讀
切換半導體／主機板／電腦周邊 → 查看同交易日漲幅前十名 → 點選股票查看詳細資料，或直接加入自選清單

目前搜尋範圍：37 檔已收錄股票，包括 2408 南亞科；半導體 13 檔、主機板與電腦周邊各 12 檔。產業採自訂分類，主機板組也包含工業電腦相關公司。完整名單在 stocks.json。

這一版尚未支援全台股搜尋。未收錄代碼會明確提示，須擴充資料名單並更新行情後才能新增。全台股搜尋屬於後續擴充項目。

04 · 資料與計算規則

  • 資料來源：Yahoo Finance，透過 yfinance 下載最近一年日線；頁面使用產出的快照，並非即時報價。
  • 收盤認定：台北當日 16:00 前排除當日日線。休市通常顯示最近交易日；供應商仍可能延遲或缺漏。
  • 價格：表格與圖表使用未還原 Close；均線判讀使用 Adj Close，兩者意義在畫面分別標示。
  • 漲跌幅：（本筆收盤價 ÷ 前筆有效收盤價 − 1）× 100%。除權息日可能不同於交易所調整參考價的漲跌幅。
  • 成交量：Yahoo 股數除以 1,000 換算成張，可能含零股小數。
  • 排行與平均：僅使用快照最新交易日的有效資料；產業排名只涵蓋自訂收錄名單，平均值不是使用者投資組合報酬。
  • 資料不足：不足兩筆價格不計算漲跌幅；不足 20 筆有效還原價不產生方向判讀；不前向填入缺值或補造行情。
  • 資料日期：首頁顯示交易日及台北時間產出時間，個股顯示各自交易日。較舊資料和失敗快取均有標示。
「下一交易日方向」是簡單均線規則，並非已訓練的機器學習模型。作品未進行預測績效回測，不宣稱準確率或上漲機率，也不構成投資建議。

05 · 實作與部署架構

stocks.json 名單 → update_data.py／yfinance → market-data.js 真實行情快照 → app.js 計算與互動 → index.html／styles.css 呈現
  • 前端使用 HTML、CSS、原生 JavaScript，不需要建置步驟；雙擊 index.html 即可使用隨附快照。
  • 自選清單只儲存在瀏覽器 localStorage，不需帳號，不上傳個人持股資訊。
  • Windows 可使用 update-data.cmd；其他環境可依 README 安裝套件並執行 Python 更新。
  • GitHub Pages 版本透過提供的 Actions 工作流程更新資料並部署，設定為工作日台北時間 16:30；必須由使用者上傳、選擇 GitHub Actions 並確認啟用。排程可能延遲。
  • 「重新讀取」按鈕重新載入行情檔，不會在瀏覽器直接執行 Python。

檢查方式：資料處理有 10 項 Python 單元測試，涵蓋換算、日期排除、無效資料、快取保留與輸出一致性；另檢查前端真實資料、缺檔與混合日期狀態，並操作瀏覽器驗證搜尋、清單保存、排行切換及走勢切換。GitHub 遠端部署尚未執行。

安裝、執行與部署的完整步驟請閱讀隨附 README.md。

06 · 與 AI 反覆調整的紀錄

以下依實際對話整理；需求摘要以使用者的選擇為主，沒有將後續構想視為已完成的功能。

輪次提出的需求／發現討論與實際修改
1 · 發想一開始沒有題目，偏好遊戲互動與生活工具。AI 提出多種方向，使用者比較後自行選擇股票觀察與預測主題。
2 · 收斂規格自選股、產業前十名，以及簡單預測。確認市場為台股，排行按當日漲幅，預測先做下一交易日方向；討論收盤更新與靜態網站的做法。
3 · 網頁原型先完成可操作網頁，之後自行上傳 GitHub。建立自選清單、產業分頁、搜尋、價格走勢與瀏覽器存檔。此時明確標示模擬資料。
4 · 視覺修正希望整體改成深色系。將背景、卡片、表格、圖表與搜尋視窗改成深色，保留台股紅漲綠跌。
5 · 真實資料版面確認後，希望串接 yfinance。移除模擬行情，加入 Python 更新、真實歷史資料、交易日、失敗快取與部署設定；先驗證 36 檔下載成功。
6 · 操作問題發現無法加入 2408。確認搜尋只限收錄名單；補入南亞科並更新 37 檔真實行情，加入自選清單並驗證。改善未收錄時的說明。
7 · 擴充討論希望能搜尋加入其他股票，不先修改名單。討論完整台股資料庫與即時後端兩種方案。全台股搜尋目前仍為後續項目。
8 · 對照評分提供包含規格書、互動、公開連結與 AI 修改證據的評分標準。整理本規格書、功能對照、限制、驗證方式與協作紀錄，首頁加入連結，部署設定包含文件。
9 · 增加實用性希望作品不只展示行情，並同意增加實用工具。加入個股筆記自動保存、收盤價條件追蹤，以及 JSON／文字備份與還原。驗證重新載入、條件達成、無效匯入攔截與還原流程，增加 10 項條件與備份單元測試。

在這次協作中學到的事

先把「想看股票」拆成市場範圍、排行依據、資料更新方式與操作流程，才能形成可實作規格。透過實際試用發現顏色偏好和搜尋限制，再逐項回饋給 AI 修改。AI 的角色是協助發想與實作，使用者則決定方向、檢查成果是否符合需求，並負責最後的公開部署與提交。
